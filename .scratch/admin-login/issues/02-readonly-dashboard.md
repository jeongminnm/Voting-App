# 02: 읽기 전용 운영자 대시보드

**What to build:** 로그인한 운영자가 `/admin` 에서 모든 투표(Poll)를 최신순으로 본다. 투표마다 질문, 만든 시각(`YYYY-MM-DD HH:mm (KST)`), 마감 상태("마감 없음" / "진행 중 · 마감: YYYY-MM-DD HH:mm (KST)" / "마감됨"), `총 N표`, 그리고 투표 화면과 결과 화면 링크가 보인다. 투표가 없으면 "아직 투표가 없습니다" 가 보인다. 삭제·수정 같은 쓰기 기능은 없다. 기존 목록·상세 조회와 투표 기능은 바뀌지 않는다.

스펙: `.scratch/admin-login/spec.md` (User Stories 13–19)

**Blocked by:** 01 (운영자 로그인 + 서명 쿠키 세션 + `proxy.ts` 경로 보호)

**Status:** ready-for-agent

### polls 데이터 접근 모듈 (추가만)

- [ ] 대시보드용 목록 조회 함수를 새로 추가한다: 모든 투표의 `id`, `question`, `created_at`, `closes_at`, 총 투표수(`sum(vote_count)`, 선택지가 없거나 0표면 `0`)를 `created_at` 최신순으로 돌려준다. 시각은 ISO 문자열(`closes_at` 은 없으면 `null`)로 바꾼다.
- [ ] neon 드라이버 행 모양을 기존 방식처럼 명시한다. `sum` 결과가 문자열이나 `null` 로 올 수 있으므로 숫자로 바꾼다.
- [ ] 기존 함수(목록 조회, 상세 조회, 투표 생성, 득표 1 증가)의 시그니처와 SQL 은 바꾸지 않는다.
- [ ] 테스트용 메모리 가짜 모듈(`test/fake-polls.ts`)에도 같은 함수를 추가한다.

### 화면 (`/admin`)

- [ ] 01 의 이중 확인(서버에서 로그인 여부 확인 후 아니면 `redirect("/admin/login")`)과 "투표 목록으로" 링크를 유지한다.
- [ ] 투표마다 질문, 만든 시각 `YYYY-MM-DD HH:mm (KST)`, 마감 상태, `총 N표`, "투표 화면" 링크(`/polls/[id]`), "결과 보기" 링크(`/polls/[id]/results`)를 보여준다.
- [ ] 마감 상태: 마감 시각 없음 → "마감 없음"; 마감 전 → "진행 중 · 마감: YYYY-MM-DD HH:mm (KST)"; 마감 후 → "마감됨". 기존 마감 판정 함수와 KST 표시 함수를 그대로 쓰고 새로 만들지 않는다.
- [ ] 투표가 없으면 "아직 투표가 없습니다".
- [ ] 요청마다 최신 값을 보여주는 서버 컴포넌트다.
- [ ] 삭제·수정·마감 조작 버튼을 두지 않는다. 화면에 "관리자" 라는 단어를 쓰지 않는다.
- [ ] 기존 Tailwind 색 체계와 다크 모드를 따른다.

### 테스트

- [ ] 이 티켓에서 새로 추가하는 자동 테스트는 없다 (실제 SQL 과 UI 는 수동 확인). 가짜 모듈에 함수를 추가해도 기존 테스트가 모두 통과한다.
- [ ] `npm run test`, `npm run typecheck`, `npm run lint` 가 모두 통과한다.

### 수동 확인 (`npm run dev`)

- [ ] 마감 없음, 마감 전, 마감 후 투표를 각각 만들어 대시보드에서 세 가지 마감 상태가 맞게 보인다.
- [ ] 투표한 뒤 대시보드를 새로고침하면 `총 N표` 가 결과 화면의 총 투표수와 같다.
- [ ] 0표 투표는 `총 0표` 로 보인다.
- [ ] "투표 화면" 과 "결과 보기" 링크가 맞는 투표로 이동한다.
- [ ] 만든 시각이 KST 로 보인다.
