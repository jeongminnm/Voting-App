# 02: 마감 판정 + 투표 화면·결과 화면 마감 표시 + API 거부

**What to build:** 마감 시각(Closing Time)이 있는 투표(Poll)는 `현재 시각 >= closes_at` 이 되면 마감된다. 마감 전에는 투표 화면과 결과 화면에 `마감: YYYY-MM-DD HH:mm (KST)` 가 보이고, 마감 후에는 투표 화면이 "마감된 투표입니다" 를 보여주며 선택지와 "투표하기" 버튼이 비활성화된다. 결과 화면은 마감 후 "마감된 투표입니다" 와 마감 시각을 함께 보여준다. 서버는 마감된 투표에 대한 투표 행위(Vote)를 `409` 로 거부하고 득표수를 바꾸지 않는다. 마감 시각이 없는 투표는 지금처럼 동작한다.

스펙: `.scratch/poll-deadline-and-chart/spec.md` (User Stories 7–14, 22, 28)

**Blocked by:** 01 (마감 시각 저장 + 생성 폼)

**Status:** ready-for-agent

### 마감 판정

- [x] 마감됨 = `closes_at` 이 있고 `현재 시각 >= closes_at`. 마감 시각 정각부터 마감이다. 서버의 현재 시각으로 판정한다.
- [x] 화면을 열어 둔 채 마감 시각이 지나도 자동으로 바뀌지 않는다 (카운트다운·폴링 없음).

### KST 표시 (ADR-0002)

- [x] 01 의 KST 모듈에 순수 함수를 추가한다: 절대 시각 → `YYYY-MM-DD HH:mm (KST)`. 실행 환경(UTC 서버 포함)의 시간대와 상관없이 같은 결과를 낸다.

### API

- [x] `POST /api/polls/[id]/vote` 가 마감된 투표에 `409` 와 `{ error: "마감된 투표입니다." }` 를 돌려주고 득표수를 바꾸지 않는다.
- [x] 확인 순서는 반드시 **없는 투표(`404`) → 마감(`409`) → 선택지 확인(`400`)** 이다. 마감된 투표에 잘못된 `optionId` 를 보내도 `409` 이다.
- [x] 마감 전 투표와 마감 시각이 없는 투표는 기존과 같다 (`200`, `{ ok: true }`).

### 화면

- [x] `/polls/[id]`: 마감 전이고 마감 시각이 있으면 `마감: YYYY-MM-DD HH:mm (KST)` 를 표시한다. 마감 시각이 없으면 마감 표시가 없다.
- [x] `/polls/[id]`: 마감 후에는 "마감된 투표입니다" 를 표시하고, 질문과 선택지는 보여주되 라디오 버튼과 "투표하기" 버튼을 모두 비활성화한다.
- [x] `/polls/[id]`: "결과 보기" 링크는 마감 전후 모두 유지한다.
- [x] `/polls/[id]`: 열어 둔 화면에서 마감 후 제출해 서버가 `409` 를 돌려주면 응답 문구("마감된 투표입니다.")를 그대로 보여준다.
- [x] `/polls/[id]/results`: 마감 전이고 마감 시각이 있으면 `마감: YYYY-MM-DD HH:mm (KST)` 를, 마감 후에는 "마감된 투표입니다" 와 마감 시각을 함께 표시한다. 마감 시각이 없으면 표시가 없다. 결과 목록·그래프 부분은 이 티켓에서 바꾸지 않는다 (03).
- [x] 두 화면 모두 서버 컴포넌트가 요청마다 최신 값으로 판정한다.

### 테스트

- [x] Route Handler 경계 (메모리 가짜, `vi.setSystemTime` 으로 현재 시각 고정):
  - [x] 마감 전 투표 → `200`, 득표수 1 증가.
  - [x] 마감 시각이 없는 투표 → `200`, 득표수 1 증가.
  - [x] 정확히 마감 시각 → `409` + `{ error: "마감된 투표입니다." }`, 득표수 변화 없음.
  - [x] 마감 이후 → `409` + `{ error: "마감된 투표입니다." }`, 득표수 변화 없음.
  - [x] 마감된 투표에 잘못된 `optionId` → `409` (404 → 409 → 400 순서).
  - [x] 존재하지 않는 투표 → `404` (마감 판정보다 먼저).
- [x] 순수 함수 경계:
  - [x] `2026-09-30T09:00:00Z` → `2026-09-30 18:00 (KST)`.
  - [x] `2026-09-30T15:00:00Z` → `2026-10-01 00:00 (KST)`.
- [x] 기존 테스트를 포함해 `npm run test` 가 모두 통과한다.

### 수동 확인 (`npm run dev`)

- [x] 마감 전 투표의 투표 화면·결과 화면에 KST 마감 시각이 보인다.
- [x] 마감이 지난 투표의 투표 화면에서 "마감된 투표입니다" 가 보이고 라디오·버튼이 비활성화되며 "결과 보기" 링크가 동작한다.
- [x] 마감이 지난 투표의 결과 화면에 "마감된 투표입니다" 와 마감 시각이 함께 보인다.
- [x] 마감 직전에 열어 둔 투표 화면에서 마감 후 제출하면 "마감된 투표입니다." 가 보인다.
- [x] 마감 시각이 없는 투표는 기존처럼 투표된다.
