# 03: 결과 페이지 퍼센트 막대그래프

**What to build:** 투표자(Voter)가 `/polls/[id]/results` 에서 선택지(Option)별 득표수 숫자 목록 대신 가로 막대그래프를 본다. 그래프 위에 `총 N표` 가 있고, 선택지마다 이름, 퍼센트에 비례한 막대, `N표 (xx%)` 가 한 줄에 보인다. 득표수가 많은 선택지가 위에 오고, 동률이면 이름순이다. 아직 아무도 투표하지 않았으면 모든 선택지가 빈 막대와 `0표 (0%)` 로 보이고 "아직 아무도 투표하지 않았습니다." 가 보인다. 마감 시각은 필요 없다 (DB 마이그레이션 없음).

스펙: `.scratch/poll-deadline-and-chart/spec.md` (User Stories 15–21, 23–24)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

### 결과 계산 (순수 함수)

- [ ] 입력: 선택지 목록(`id`, `label`, `vote_count`). 출력: 총 투표수와 선택지별 `label`, `vote_count`, 표시용 정수 퍼센트, 막대용 정확한 비율.
- [ ] 퍼센트 = `Math.round(vote_count / 총 투표수 × 100)`. 합계가 100% 가 되도록 보정하지 않는다 (99%·101% 허용).
- [ ] 막대 비율은 반올림 전 정확한 값(`vote_count / 총 투표수`)이다.
- [ ] 총 투표수가 0 이면 모든 퍼센트와 비율은 0 이다.
- [ ] 정렬: 득표수 내림차순, 동률이면 선택지 이름을 한국어 기준(`localeCompare(…, "ko")`) 오름차순으로 정렬한다. DB 조회 SQL 과 스키마는 바꾸지 않는다 (투표 화면 순서는 기존대로 DB 순서).

### 화면

- [ ] `ResultBar` 컴포넌트가 계산된 결과 한 줄(이름, 득표수, 퍼센트, 비율)을 받아 그리기만 한다: 선택지 이름, 회색 배경 막대 안을 정확한 비율만큼 채운 막대, `N표 (xx%)`.
- [ ] 채움 색은 기존 버튼과 같은 전경색(`bg-foreground`)이고 모든 막대가 같은 색이다. 빈 부분은 회색이다. 기존 색 체계와 다크 모드를 유지한다. Tailwind 만 쓰고 차트 라이브러리는 쓰지 않는다.
- [ ] `/polls/[id]/results` 의 숫자 목록을 가로 막대그래프로 교체하고, 그래프 위에 `총 N표` 를 표시한다.
- [ ] 투표가 0 건이면 `총 0표`, "아직 아무도 투표하지 않았습니다.", 모든 선택지를 빈 막대와 `0표 (0%)` 로 표시한다.
- [ ] 결과 화면은 서버 컴포넌트로 유지하고 요청마다 최신 득표수를 보여준다. 기존 링크(투표 화면으로, 목록으로)와 없는 투표의 404 는 유지한다.
- [ ] 02 의 마감 표시가 먼저 들어가 있으면 그대로 둔다 (그래프 부분만 바꾼다).

### 테스트 (순수 함수 경계)

- [ ] 0표: 총 0, 모든 선택지 0% · 비율 0.
- [ ] 1표: 받은 선택지 100% · 비율 1, 나머지 0%.
- [ ] 동률: 같은 득표수는 같은 퍼센트이고 이름순으로 정렬된다.
- [ ] 반올림: 1/3 → 33%, 2/3 → 67%, 1/8 → 13%.
- [ ] 막대 비율은 반올림 전 정확한 값이다 (예: 1/3 → 1/3).
- [ ] 정렬: 득표수 내림차순, 동률이면 이름 오름차순.
- [ ] 기존 테스트를 포함해 `npm run test` 가 모두 통과한다. 컴포넌트 테스트, Testing Library, jsdom 은 추가하지 않는다.

### 수동 확인 (`npm run dev`)

- [ ] 결과 화면에 `총 N표` 와 선택지별 막대·`N표 (xx%)` 가 득표순으로 보인다.
- [ ] 새로 만든 투표의 결과 화면에서 `총 0표`, "아직 아무도 투표하지 않았습니다.", 빈 막대가 오류 없이 보인다.
- [ ] 투표 후 이동한 결과 화면에 방금 한 투표가 막대에 반영되어 있다.
- [ ] 다크 모드에서도 막대가 잘 보인다.
