# v1은 인증 없는 익명 투표이며 중복 투표를 막지 않는다

v1에서는 투표자 로그인, 운영자 인증, 중복 투표 방지를 구현하지 않는다. 누구나 투표(Poll)를 만들고 투표할 수 있으며, 같은 사람이 여러 번 투표하는 것을 막을 방법이 없다. 이는 "질문을 올리면 사람들이 선택지를 고르고 결과를 본다"는 원래 요청 범위를 단순하게 지키기 위한 의도적 선택이며, 신뢰성보다 단순함을 우선한 트레이드오프다.

현재 결정: 이 ADR의 역사적 v1 결정은 그대로 보존한다. 투표자는 계속 로그인 없이 익명으로 참여하고 중복 투표도 허용한다. 다만 운영자 인증을 구현하지 않는다는 부분은 현재 운영자 인증을 도입한 [ADR-0003](0003-admin-login-with-admin-token-cookie.md)으로 대체되었으며, 운영자 로그인·세션·대시보드의 상세 요구사항은 `.scratch/admin-login/spec.md`에서 관리한다.
