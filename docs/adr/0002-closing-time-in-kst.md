# 마감 시각은 항상 한국 시간(KST, Asia/Seoul)으로 해석하고 표시한다

투표를 만들 때 입력하는 마감 시각(`datetime-local`)은 입력한 사람의 브라우저 시간대가 아니라 항상 KST 로 해석해 `+09:00` 이 붙은 절대 시각으로 서버에 보내고, 화면에도 항상 KST 로 표시한다. DB 에는 절대 시각(`timestamptz`)으로 저장한다. 이 앱은 동아리 투표용이라 참여자가 모두 한국에 있다고 보고, 서버 컴포넌트가 UTC 시간대의 서버(Vercel)에서 렌더링될 때 마감 시각이 9시간 어긋나 보이는 문제를 피하려고 이렇게 정했다. 해외 참여자를 지원하려면 입력, 변환, 표시를 모두 다시 설계해야 한다.
