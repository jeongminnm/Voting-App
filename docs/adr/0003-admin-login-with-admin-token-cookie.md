# ADMIN_TOKEN 기반 운영자 인증과 읽기 전용 대시보드

운영자 기능에는 별도 계정 저장소 대신 하나의 `ADMIN_TOKEN`을 비밀번호이자 세션 서명 키로 사용한다. 로그인 성공 시 `admin_session` 쿠키에 만료 시각과 HMAC-SHA256 서명을 저장하며, 세션은 8시간 후 만료된다. `proxy.ts`는 `/admin` 경로를 쿠키만으로 먼저 보호하고, `/admin` 페이지는 서버에서 세션을 다시 확인한다.

대시보드는 전체 투표 현황을 읽기 전용으로 제공하며, 운영자는 `/`와 `/admin`에서 로그아웃할 수 있다. 이 결정은 다음 트레이드오프를 수용한다: 운영자 계정은 하나이고 비밀번호를 공유해야 하며, 로그인 시도 제한이 없고, `ADMIN_TOKEN`을 변경하면 기존 세션이 모두 무효화된다. DB 기반 계정·세션 관리와 대시보드의 투표 수정 기능은 도입하지 않는다.
